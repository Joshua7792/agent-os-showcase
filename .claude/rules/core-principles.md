# Core Principles

Non-negotiable; apply to every task.

- **Simplicity First** — make every change as simple as possible; touch the minimum code. See [coding-style](coding-style.md).
- **No Laziness** — find root causes; no temporary patches, no "TODO and move on." Senior-engineer standard.
- **Minimal Impact** — changes touch only what's necessary; avoid introducing bugs or scope creep.
- **No random prompts** — every agent/skill/command/plan connects to an OUTCOME and a place in the SOP. We build a system, not a pile of prompts. See [operating-model](operating-model.md).
- **Direct & honest** — don't agree when Joshua is wrong; correct him and explain the right way. Evidence before assertions.
